# D1 Continuity Test Protocol

> Version: 0.1  
> Status: ACTIVE TEST SPEC  
> Asset: D1 v1.1 Production Master Candidate

This file defines how to test whether the D1 emblem can survive AI-video generation without losing its identity.

D1 is not final MASTER yet.

It may only become `D1 MASTER v1.0` after staged continuity tests pass and the Executive Producer explicitly approves it.

---

## Core rule

> DO NOT REDESIGN D1.  
> FILM IT.

Treat D1 as a manufactured physical object already attached to the protagonist's backpack.

AI video tools are not allowed to reinterpret, complete, simplify, symmetrize, rotate, or replace it.

---

## Critical identity anchors

Each test must evaluate these five anchors.

### 1. BROKEN ZERO

The incomplete, asymmetric outer zero/ring remains recognizable.

Fail condition:

- becomes a clean full circle
- becomes a generic glowing ring
- loses major missing segments

---

### 2. A AXIS

The rising diagonal/angular A-like structural axis remains recognizable.

Fail condition:

- turns into random lightning
- collapses into an abstract line
- becomes symmetrical logo geometry

---

### 3. LOWER-RIGHT FRACTURE

The distinctive lower-right broken/missing structure remains visible.

Fail condition:

- fracture disappears
- lower-right area becomes filled in
- break changes into unrelated decoration

---

### 4. CENTRAL CORE

The cyan core remains in the correct relationship to the emblem.

Fail condition:

- core moves randomly
- core disappears
- core becomes large unrelated light source

---

### 5. BACKPACK PLACEMENT

The emblem remains fixed on the backpack with stable size, orientation and placement.

Fail condition:

- emblem floats off the backpack
- emblem changes size dramatically
- emblem rotates/mirrors randomly
- emblem moves to clothing or environment

---

## Test order

Run one test at a time.

Do not batch tests.

1. TEST A — BACK CLOSE-UP
2. TEST B — FULL BODY / DISTANCE
3. TEST C — DARK / HEAVY RAIN
4. TEST D — WALKING

Only proceed to the next test after the previous test passes.

---

## Passing standard

A test should pass only if the D1 identity is preserved clearly enough for recurring production.

A beautiful video with a mutated D1 fails.

A less dramatic video with stable D1 may pass.

Continuity is the priority.
