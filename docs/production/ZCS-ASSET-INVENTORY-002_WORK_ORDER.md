## 事前の正史確認（必須）
- EP00『正しい世界』本文v08の承認原本、承認日時、保管先、版を確認。内容が確認できなければ映像の正史整合をPASSにしない。

- GitHubの `episodes/TEASER00/TEASER00_SCRIPT.md` は「¥0から始めるAI副業」「MISSION 01」等を含む旧企画資料。現行EP00の承認済みティザー脚本として使用しない。
- `ZERO_CODE_RULES.md` の匿名フード主人公・D1・実収益連動ストーリー等の記述と現行承認設定の不整合を、規程変更の検討課題として列挙する。監督・Workの独断で既存規程を書き換えない。現行脚本と矛盾する演出を制作に持ち込まない。

## Phase A｜現行EP00素材の棚卸し
1. 現行OS資産68レコードと制作フォルダから、EP00 v08に対応する人物挿絵・背景・カフェ・雨・救助場面・小道具・音声の候補を照合。
2. Kling元5秒TESTおよび縦型A/B/Cを既存の `TEASER00-KLING-REVIEW-002` 記録と照合。Cは制作側第一候補にすぎず、監督の全速視聴合格ではない。
3. 各素材の既存ID、相対パス、SHA-256、生成履歴、利用条件、脚本の対応節、承認根拠、用途（静止／背景／演技用基準画／完成カット）を記録。
4. 既存のMASTER／APPROVEDを自動転用せず、権利不明は未確認とする。OSの既存ID・状態・承認履歴を保全。
5. 監督レビュー用に「EP00に使える」「修正が必要」「技術参考のみ」「未確認」を理由付きで提出。これらは台帳の正式ステータスとは別の**再利用評価**である。

## Phase B｜演技テストの設計（追加生成なし）
- 第05節のカフェ場面が現行脚本と一致することを確認できた場合に限り、ユナの視線・首・指先・呼吸・姿勢・雨との関係を5秒で伝える演技プランを設計。
- 最小3ポーズ（開始／中間／終了）と動作タイミング、重心、視線のターゲット、動かさない部分、音・環境の役割を記述。
- 既存画像だけで検証できる構図・編集・アニマティクスを先に提案。顔・手の破綻、衣装・バッグの不一致、局所ちらつき、背景の歪みを品質ゲートとする。
- Kling C案は雨・光・構図の参照候補として保持。透かしレイヤーの境界、画角欠損、全速再生、商用利用条件の未解決を明記。
- 実際の新規生成・クレジット消費・公開・MASTER昇格は行わず、生成が必要な場合は候補・想定費用・必要な承認を提出する。
