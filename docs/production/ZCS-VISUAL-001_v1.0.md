## 1. 最重要制作目標（プロデューサー決定）
> **ユナの雨のカフェのコンセプト画像で示された映画的な日本アニメの映像美を、作品全体の品質目標にする。**
>
> **既存の挿絵にアニメの品質を合わせるのではなく、この映像美を目標にアニメ用素材を設計する。**
>
> **AIを使って制作しても、視聴者がAI特有の不自然さを意識しない作品を目指す。**

この3点を今後の演出・背景美術・撮影処理・キャラクター演技のレビューで毎回参照する。静止画1枚の良さを「動画としての合格」と混同しない。

## 3. 画づくりの基準
| 項目 | 目標 | 禁止・修正対象 |
| --- | --- | --- |
| 作画 | 精密で自然な日本アニメの線、安定した顔の造形、統一した彩色 | カットごとの別人化、目・鼻・髪の分け目の漂流 |
| 色彩 | 雨の青・冷たい都市光と、室内の琥珀色・暖色の対比 | 無意味なネオン増殖、飽和しすぎた色 |
| 光 | 人物と背景が同じ空間にあると感じられる陰影と反射 | テカテカした肌、過剰なグロー・ブルーム、輪郭が溶ける逆光 |
| 背景 | 描き込みの密度、奥行き、雨・窓・室内の一貫性 | 窓枠・街並み・小物のフレーム間変形 |
| 演技 | 視線の動機、間、表情の微細な変化、静と動のメリハリ | 常時揺れる髪・服・肩、意味のない身振り |
| カメラ | 意図のある構図、必要なときだけ動く撮影 | 無目的なズーム、ドリー、回転、過剰なパララックス |
| 音響 | 間・呼吸・雨・声で感情を支える | 過剰なSE、口パクと音声の不一致 |

※雨のカフェは画風の基準であり、全シーンを雨・青橙・カフェにする指示ではない。昼・屋外・救助・緊迫など各場面の光と感情に応じて変奏する。

## 4. キャラクターと正史
- 既存の承認済み人物設定・脚本・承認履歴を優先し、画風の更新と設定の変更を分離する。
- 今回のコンセプト画像の顔・髪型・衣装・カップ・背景を、そのまま正式ユナのMASTERにしない。
- 小説版EP00『正しい世界』v08の雨粒観察→つぶやき→小さな笑みという感情の因果を守る。
- リポジトリ内の旧「¥0から始めるAI副業」/匿名フード主人公/D1の旧企画と、現行EP00の正史を混ぜない。旧資料は削除せず、適用範囲の不整合を別途是正する。

## 5. 制作方式（当面の標準）
**原画主導のハイブリッド制作。**
1. 承認済み脚本と人物・背景資料を照合する。
2. 画風・構図・演技を絵コンテで定義する。
3. 同一人物・同一カメラのキー原画を必要数だけ制作する（目安3〜6枚、固定枚数ではない）。
4. 動画生成AIまたは局所作画・中割りをカットの特性に応じて使う。必要ならA/B比較する。
5. 顔・目・口・手・衣装・背景の破綻を局所修正する。全画面クロスフェードだけの紙芝居を完成アニメと認めない。
6. 動画全尺の実時間視聴・コマ単位検査・聴感・スマホ視聴・権利確認を通す。

## 6. AI感低減の品質ゲート
- **Identity:** 同一キャラの顔・体格・瞳・髪・衣装・小物の形がカット内外で一致する。
- **Acting:** 何を見て、何を感じ、なぜ動いたかが映像から分かる。不要な動きは止める。
- **Continuity:** 雨粒と視線、手と小道具、体重と接地点、背景パースの因果が成立する。
- **Rendering:** フリッカー、溶解、手指の異常、肌の過剰光沢、グロー増殖、勝手なカメラ移動が目立たない。
- **Narrative:** 美麗さのために脚本外の行動や設定を追加しない。
- **Delivery:** 全速視聴と音声確認なしに完成判定しない。権利未確認・透かし未解決なら公開しない。

評価区分は **PASS / REWORK / FAIL / UNVERIFIED**。一枚絵の美しさだけでPASSにしない。参照: [ユナ5秒A/B計画](EP00_YUNA_ANTI_AI_AB_TEST_PLAN.md)。

## 7. 今回の承認境界
- **承認されたもの:** アニメ版の映像美の方向性、AI感低減、原画主導ハイブリッド方式を制作目標とすること。
- **承認されていないもの:** 生成画像そのもののMASTER化、正式キャラのデザイン変更、動画完成・公開、課金、商用利用条件の確定、旧正史の統合。
- ZCS-ASSET-001 v1.0を維持し、既存68資産のID・状態・承認履歴を無断変更しない。
- 本文は既存の `ZERO_CODE_RULES.md` を上書きしない。旧ルールとの正史衝突は [別資料](LEGACY_CANON_CONFLICTS_PRELIMINARY.md) に記録し、正式改訂は別承認とする。
