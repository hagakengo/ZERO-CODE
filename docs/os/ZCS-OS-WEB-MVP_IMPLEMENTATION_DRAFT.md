## 調査と保全の基準

GitHub main調査基準は8db52c6。既存のNext.js/React/TypeScriptとFastAPIを再利用する。旧FastAPIのSQLiteは運営指標・外部連携用であり、ローカル版の制作JSONと同一データ基盤ではない。ローカル版にはGitHub mainにない制作台帳・編集API・原稿リーダー・Basic認証がある。

旧D1等の企画資料は参照資料として保持し、現行EP00ユナの正史へ転用しない。ZCS-VISUAL-001の画風方向承認とキャラクターMASTER承認は別に扱う。

## 現行のデータ取得・確定方式

1. 運用者が非公開設定で制作JSON、許可素材ルート、版ごとの制作パッケージを明示する。アプリ起動時には取り込まない。
2. `backend/tools/build_studio_snapshot.py`を明示実行する。完成先は既存ディレクトリを指定できず、原本・旧コピーを置換しない。
3. 同じ親ディレクトリ内の非公開一時領域でコピーを作る。コピー前後のSHA、サイズ、元ファイルのinode・更新時刻、元台帳SHAを検証する。
4. レシートとmanifestの保存後、manifestハッシュを持つ完了マーカーを書き、最後にディレクトリをrenameして閲覧用スナップショットを確定する。完了マーカーは破損検出用であり電子署名ではない。
5. コピーI/O異常、ENOSPC、コピー中の元ファイル変更、全体容量超過、レシート保存失敗では取り込み全体を中止し、完成先を作らない。単一ファイル容量超過・許可ルート外・非対応形式・初めから未取得の素材は代替せず、未取得として表示する。
6. Readerはschema v2、完了マーカー、閉じたDTO型を要求する。未完了・取り込み一時領域・未知DTO項目・旧schema v1は拒否する。旧コピーの自動昇格はしない。
7. 配信直前にも素材SHAを照合する。任意パス・任意URL・シンボリックリンク・改ざんは拒否し、許可された論理IDだけを扱う。

現行の閲覧コピーは**71素材DTOと68種類の画像・動画ファイル**。EP00 r01〜r03の原画24枚・動画3本を含む。同じファイルの再利用があるため、DTO件数とファイル種類数は一致しない。

## 開示範囲と機密情報

- 画像PNG/JPEG・動画MP4のみ配信する。HTML/SVG・原文Markdown/JSON/CSV等は配信しない。動画Range GET/HEADをサポートし、全応答をprivate/no-store、nosniffとする。
- メモ、レビュー詳細、タイムシート等の**原文資料の閲覧再開は、構造化DTOと開示範囲の審査後**とする。現在はUIにも非配信を明示している。原本と旧コピーは削除していない。
- 閲覧DTOは必要項目に限定する。自由記述は既定で非表示とし、内容を確認した個々の値のSHA-256を非公開設定`approved_text_sha256`で許可する。値が変われば再確認が必要。
- タイトル・原台帳の状態・版の表示値は今回確認し、値単位で許可した。原本パス、未確認の履歴メモ・レビュー原文は渡さない。日時の省略は「非表示」とし、原本に記録がないと断定しない。
- Mac/Unix/Windowsパス、URL中の認証情報、鍵・トークン表記、メール・電話番号等の検出は補助防御。パターンに一致しない自由記述も、値の許可がなければ配信しない。正規表現が全個人情報を検出できるとは評価しない。
- 原画名はK番号、保管先は`private-copy://`論理参照を用いる。元の絶対パスと照合レシートは非公開領域で保持する。公開Gitへ実データ・素材・認証情報・私有設定・画像証拠を追加しない。
- 個別値の閲覧許可と、作品・素材の正式採用承認は別である。

## 認証と配信の範囲

ブラウザ → Next.js → 専用FastAPI Readerの順で接続する。FastAPI向けBearerトークンはブラウザへ渡さない。専用Readerに既存の更新・指標・外部連携APIは登録しない。

`STUDIO_AUTH_MODE=local-pilot`を明示した単一閲覧者の検証用認証のみ実装する。未設定・public・未知のモードは拒否する。ログインと保護ルートはloopbackホストに限定し、両サービスを127.0.0.1にバインドする。署名付き6時間CookieはHttpOnly/SameSite=Strict、セッション検証はmiddlewareとBFF双方で行う。

現行のログイン試行制限は単一プロセス用。ログアウトはブラウザCookieを削除し、署名秘密の変更は全既存セッションを無効化する。個別セッションのサーバー側失効・MFA・複数役割・公開認証モードは未実装。

期限切れ後の原画・動画の新規GET/HEAD/Rangeリクエストは401で拒否する。既にブラウザへ渡したフレームやダウンロード済みバイトを回収する機能はない。

**外部公開前の必須条件：共有レート制限、サーバー側セッション失効、HTTPS、監査ログ、認証・認可・非公開配信設計の承認。** 現行の認証を公開用と扱わず、認証のない旧APIや別画面をインターネットへ公開しない。

## 隔離環境での起動・検証

ローカル検証はPython3.12、GitHub CIはPython3.11を使用した。閲覧専用の依存を分離し、既存requirements.txtは変更していない。

```sh
cd backend
python3.12 -m venv .venv-reader
.venv-reader/bin/pip install -r requirements-reader.txt
.venv-reader/bin/python -m unittest -v test_studio_reader
```

非公開の取り込み設定例：

```json
{
  "production_file": "<private-production-json>",
  "media_roots": ["<private-media-root>"],
  "packages": [
    {"version": "r01", "path": "<private-r01-package>"},
    {"version": "r02", "path": "<private-r02-package>"},
    {"version": "r03", "path": "<private-r03-package>"}
  ],
  "max_file_bytes": 30000000,
  "max_total_bytes": 1000000000,
  "approved_text_sha256": []
}
```

許可リストが空なら自由記述は非表示になる。元台帳全体を一括許可せず、個別値の開示範囲を確認する。

```sh
backend/.venv-reader/bin/python backend/tools/build_studio_snapshot.py \
  --config /private/operator-config.json --destination /private/NEW-snapshot
```

サーバー側の設定：

- `STUDIO_AUTH_MODE=local-pilot`：Next.jsのローカルモード明示。
- `STUDIO_SNAPSHOT_DIR`：Reader用の確定済み私有コピー先。
- `STUDIO_READER_TOKEN`：32文字以上。Next.jsとReader間だけで共有。
- `STUDIO_READER_URL`：Next.jsから見たReader。検証ではhttp://127.0.0.1:8135。
- `STUDIO_VIEWER_USER`、`STUDIO_VIEWER_PASSWORD`：単一閲覧者ログイン。テスト値を実運用へ流用しない。
- `STUDIO_SESSION_SECRET`：32文字以上のランダム値。変更時に既存セッションは無効。

秘密は`NEXT_PUBLIC_`に設定しない。ローカルOSの既存ログインは変更・流用していない。Readerは`uvicorn app.studio_reader:app --host 127.0.0.1 --port 8135`、Next.jsはビルド後`next start --hostname 127.0.0.1 --port 3135`で起動する。0.0.0.0へ変更して公開しない。

フロント検証は`npm run test:studio`と`npm run build`。実HTTPの期限切れ検証は`backend/tools/check_studio_http.py`を使い、`STUDIO_TEST_URL`と対象のテスト用サーバー環境変数を安全に渡す。URLはloopback限定。認証情報をチャット・ログ・Gitへ出力しない。

## 保全・復元

原本JSONの非公開バックアップとSHAを保持し、隔離領域で再読込・等価復元を確認済み。原本には書かないため、通常は復元操作を必要としない。実際の復元は後続revisionを確認し、現行版を保全したうえで別承認とする。古いrevision35を本番へ無条件に戻さない。

コピー更新は新規ディレクトリへ実施し、照合後に閲覧用サービスの設定だけを切り替える。旧コピーを保持し、本番データを変更しない。
