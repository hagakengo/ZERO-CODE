# ZERO CODE — PRODUCTION RULES

> Version: 0.1  
> Status: ACTIVE  
> Purpose: Hard constraints for humans and AI agents

---

## 1. Authority order

When instructions conflict, use this priority:

1. latest explicitly approved MASTER asset
2. this file
3. Visual Bible
4. PROJECT_CONTEXT
5. episode-specific specification
6. AI assumptions

AI assumptions have the lowest authority.

---

## 2. Canon approval

Nothing becomes canon simply because:

- it was generated
- it looks good
- it appeared in a draft
- an AI called it final

Major canon changes require explicit Executive Producer approval.

Until approved, label work as:

- DRAFT
- CANDIDATE
- PROTOTYPE
- TEST
- EXPERIMENT

Never silently promote a candidate to MASTER.

---

## 3. Story rules

- Settings may be fixed.
- The final outcome must not be predetermined.
- Never fabricate real-world followers, revenue, sales or milestones.
- Real results may alter the fictional story.
- Failure is valid story material.
- Unexpected events are valid story material.

Core principles:

> 設定は固定する。でも結末は決めない。

> 数字を盛らない。現実を脚本にする。

---

## 4. Protagonist — absolute rules

- Face must never be clearly visible.
- Keep the same identity and silhouette.
- Black oversized hoodie.
- Black / charcoal cargo pants.
- Black sneakers.
- Angular black tech backpack.
- No weapons.
- No random accessories.
- No redesign between shots.

Preferred camera views:

- rear
- 3/4 rear
- obscured side silhouette

---

## 5. Lighting — absolute rule

> THE PROTAGONIST DOES NOT GLOW.  
> ONLY ZERO CODE GLOWS.

Forbidden:

- cyan hoodie seams
- fluorescent clothing lines
- neon pants trim
- glowing sneakers
- decorative glow accessories

Use material differences to reveal form.

---

## 6. Backpack rule

The backpack is a canonical asset.

After geometry is finalized:

- preserve geometry
- preserve size relationship to body
- preserve strap layout
- preserve emblem location
- preserve emblem scale

Before EP.01 awakening:

- backpack blank

After `ZERO CODE DETECTED.`:

- emblem appears
- emblem remains canonical

---

## 7. D1 status

Current status:

**D1 v1.1 — Production Master Candidate**

NOT YET:

**D1 MASTER v1.0**

Promotion requires:

- continuity tests
- acceptable repeatability
- explicit Executive Producer approval

---

## 8. D1 geometry anchors

Always preserve:

### BROKEN ZERO
Incomplete asymmetrical outer zero/ring.

### A AXIS
Rising diagonal/angular A-like axis.

### CENTRAL CORE
Cyan glowing core in MASTER-relative position.

### LOWER-RIGHT FRACTURE
Distinctive lower-right missing/broken section.

### INTERRUPTED PATH
Incomplete surrounding path/orbit.

---

## 9. D1 forbidden changes

Never:

- complete the zero into a clean circle
- make it symmetrical
- clean up intentional fractures
- rotate arbitrarily
- mirror arbitrarily
- change aspect ratio
- relocate central core
- change primary cyan glow
- add a literal infinity symbol unless explicitly approved
- add decorative micro-detail that harms reproducibility
- substitute another emblem
- reinterpret it shot-by-shot

Production instruction:

> DO NOT REDESIGN D1. FILM IT.

> DO NOT RECREATE IT. FILM THE EXISTING OBJECT.

---

## 10. D1 test protocol

Run sequentially:

A → B → C → D

Do not batch.

### TEST A
Back close-up. Still subject. Slow push-in.

### TEST B
Full body / distance.

### TEST C
Dark / heavy rain.

### TEST D
Walking.

Score each test:

- BROKEN ZERO
- A AXIS
- LOWER-RIGHT FRACTURE
- CENTRAL CORE
- BACKPACK PLACEMENT

---

## 11. Visual style rules

Primary:

- 9:16 vertical
- black / dark blue
- cyan / electric blue
- orange sparks/fire accents
- wet reflective surfaces
- volumetric fog
- cinematic depth
- gigantic architecture
- cyberpunk AI city
- anime/game-cinematic tone

The world should generally feel much larger than the protagonist.

---

## 12. HUD rules

HUD must be:

- readable
- restrained
- translucent
- game-like
- visually consistent

Exact copy should preferably be created in post-production.

Do not trust a video model to preserve critical text.

---

## 13. Episode quality gate

Do not publish a major episode unless:

1. protagonist continuity passes
2. backpack continuity passes
3. emblem continuity passes
4. no severe AI-motion artifacts
5. first 3 seconds are strong
6. visual storytelling is clear
7. ending creates desire for the next episode
8. displayed real-world metrics are accurate

Quality > forced schedule.

---

## 14. Asset change rule

Never overwrite an approved MASTER when exploring a redesign.

Example:

`D1_MASTER_v1.0`

→ create

`D1_v1.1_CANDIDATE`

→ test

→ approve or reject

→ promote only after approval

Preserve history.

---

## 15. Production logging rule

For meaningful tests record:

- date
- version
- tool/model
- input/reference assets
- prompt version
- goal
- result
- what worked
- what failed
- what changed
- why it changed
- status
- next action

---

## 16. Archive rule

Never erase failed work simply because it failed.

Store:

- prototypes
- rejected concepts
- failed generations
- prompt experiments
- continuity failures

These are production evidence and possible future behind-the-scenes assets.

---

## 17. AI role rule

All AI agents must serve the same ZERO CODE canon.

> ZERO CODEは1つ。AIはそれぞれ専門スタッフ。

No model is allowed to create its own independent canon.

---

## 18. Core production principles

> 生成AIはデザイナーではなく撮影スタッフ。

> 最高の1枚ではなく、最高の世界を壊さず作り続ける。

> 現実で起きたことが正史になる。

> ZERO IS NOT NOTHING.

> ZERO IS WHERE EVERYTHING BEGINS.
