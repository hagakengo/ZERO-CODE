# ZERO CODE AI CITY A/B 独立美術QA

判定：両案とも比較用DRAFTとして提示可能。採用判断はユーザー確認待ち、動画化HOLD、採用済み完成映像0秒。

基準KF_015、A、BとC/FILM人物クロップを直接目視確認。制作担当とは別のQA担当による評価。

- **構図**：中央の帯光タワー、左右の塔、橋、右壁、路面の消失方向はよく保持。完全固定ではない。Bは塔の上端・屋上設備、雲の形、前景の縁と下部の段差が変化し、輪郭が明瞭になった。大幅な巨大建築追加は見られない。
- **空気と光**：両案とも深い黒、冷たい青の帯光、少量の暖色窓灯、雨と濡れた路面を保持。Aの霧の柔らかさと暗さが基準に近い。Bは雲・塔の輪郭を強めた分、基準より霧の包み込みがやや弱い。
- **画風差**：Aは細かい濡れた材質と連続的な陰影を残す。Bは壁・雲・路面を大きめの筆触と色面で整理し、2D背景への接続が分かる。差は確認できるが、別物ほど大きくない。Aにも筆触があり、Bにも強い反射が残る。
- **前景遮蔽物**：両案とも目地と直線、上部梁との連続により建築の縁として読める。基準の脚状の曖昧さは大きく改善。下部の斜めの段差は双方に残り、特にAは細部が砕け気味。
- **生成由来の懸念**：致命的な形状破綻は目視では認めない。ただし手すり・配管・細い窓列の接続、前景の目地や欠けは不均一。路面反射の反復感も残るため、最終美術としての確定には拡大確認が必要。
- **C/FILMとの相性**：輪郭と陰影の面が明瞭な人物には、色面を整理したBが合わせやすいと推定。Aも色調は合うが、材質の密度が人物より強い。実合成をしていないため相性の確定評価ではない。

**選び方**：基準の湿った重厚感を優先するならA。人物と2D背景の絵柄の接続を優先するならB。両案をユーザーが見て選ぶための比較として成立するが、「画風だけが完全に変わった比較」とは言い切れない。
