SVGは制御点を編集できる新規ベジェ構造ラフ。透明PNGは出力画像であり、それ自体は編集可能な線画ではない。Blender版は同じベジェを点列へ展開したネイティブGREASEPENCILの静止プロジェクト。線/塗/描画順を保持し、ラスタ原顔・肌色修復パッチを含めない。自動点列化を人間の手描き原画と報告しない。
