## 制作方法と再現

基準は `c4122d55d48826e66f8be906a20e20b0cfe38871` の1536×1024モデルシート。元A+BボードとC/FILM比較もGitの画像実体を取得して目視。参照コピーと出典・SHA-256は [references.json](source/references.json) に記録。参照原本は変更していない。

内蔵 Image Gen を1回使用。既存3画像を渡し、同じ人物の連続原画8枚を1シートに編集するよう指示した。[実際のプロンプト](source/prompt_v01.txt)を保存。生成モデル名はツールから非公開。チャットのモデル切替後の正確なモデルIDも確認できないため、Astra制作と表記しない。サブエージェントなし、単一タスク。外部有料動画サービス・課金API・追加購入なし。内蔵画像生成の利用枠は消費する。

8枚を等分切り出し、K01を12フレーム、K02〜K07を各3フレーム、K08を18フレーム露出している。48枚の独立した原画を描いたという意味ではない。カメラは固定。追加の変形、中割り生成、オプティカルフロー、ズーム、パン、クロスフェード、肌パッチ、顔のベジェ描画は行っていない。

再ビルド（Python 3標準ライブラリ、FFmpeg/ffprobe、libx264 が必要）：

```sh
python3 source/build.py
```

保存済み原画からキーPNG・48フレーム・MP4・比較画像・検査JSONを再作成できる。原画のAI再生成は非決定的なので再現の対象外。`frames/` は再生成可能な重複PNGとしてGit対象外。
