## 具体的な差分

旧版は固定胴体と輪郭ワープ、位置移動が中心。今回は元の人物PNG・PoseDraw・LegDraw・位置補間を使わず、18個の明示的なポーズデータから各作画の輪郭を構成した。生成モデル画像・動画は使用していない。これは輪郭描画プログラムによるデジタル作画であり、手描きの鉛筆原画とは異なる。共通の輪郭描画関数を使うため、完全に独立した自由曲線原画でもない。

骨盤と肩の逆傾斜、重心の沈み込み、膝の位置と曲げ、蹴り足の爪先支点回転、腕の逆振り、フードの独立位置、バッグの遅れ、裾の遅れを作画ごとに指定。静止3コマ、通常2コマ、加速・切り返し1コマ、終端3コマ。F216〜229／F230〜245の枠を維持しつつ、切り返し荷重を境界付近に再設計した。雨・残像・カメラシェイクは追加せず、背景も固定。旧版の雨は比較左側にのみ残る。

## 自己批評・残課題

- 姿勢差と左右への体重移動は静止作画で確認できる。ただし自然な運動として読めるかは通常速度の連続視聴が必要。画像枚数や関節座標の変化だけでは改善の証拠にしない。
- 輪郭は角張った簡略表現で、袖・肘・膝の体積や布の皺が少ない。共通描画関数による硬さが残り、「本格2Dアニメ完成」には届いていない。見た目の紙芝居感を解消できたとは断定しない。
- 蹴り出しから前足接地までの足運び、後脚が浮く区間、接地位置と遠近の整合は重点批評箇所。足の影を各足首の位置に合わせたが、物理シミュレーションでの接地保証ではない。
- 骨盤／肩の逆ひねりは背面の傾斜とシルエットで表現。胴体の奥行き回転、バッグの遠近短縮は弱い。角形バッグは無地を維持するが、元版との寸法比率・絵柄の完全一致は未承認。
- フードと裾の遅れは個別ポーズ指定。布の自然な波やフードの細かな変形は不足している。
- 旧版の原画そのものは保持。今回の開始・終端姿勢は再作画のためS03／S05との接続保証なし。本編接続前に別途レビューが必要。
- 正式キャラクター画像はVisual Bibleの推奨パスに実体なし。今回の設定根拠はルール／Visual Bible／既存S04。正式設定を新たに確定していない。
