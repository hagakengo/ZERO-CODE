## 実際の制作方法と限界

built-in image_genで15ポーズを一枚のシートとして生成し、セルをFFmpegで分割、露出表に従って30フレームへ編集した。身体・脚・服を描き分けたラスター原画であり、箱型仮人物やパーツ回転リグは使用していない。位置移動、輪郭ワープ、モーフ、光学フロー、フレーム補間もなし。ただし、人間のアニメーターによる手描き原画・中割りではない。**AI生成原画のコマ撮り試作であり、本格2D作画の完成品とは呼ばない。**

制作順はアクション原画とデザインの同時試作→その原画を参照した設定画展開。設定画を先に確定して動画モデルで動かしたものではない。人物の候補は共通だが、設定画ではバッグの装飾を減らす指示を追加したため、動画との細部一致は未達。設定画・動画ともDRAFT。

生成シート実寸1619×971、各原画は約320×320。動画は拡大して1080×1920の固定余白付きビューに載せている。1080×1920で原画を描き下ろしたと誤認しないこと。灰色の作画チェック背景で、AI CITYの本編レイアウトではない。格子境界の細線・背景明度差も残る。

この環境の画像生成ツールは連続動画や厳密な関節・足の接地を保証する機能を提供しない。そのため高解像度で統一された全身作画、中割り精度、接地の連続性を要求水準まで達成していない。動画ファイルは完成しているが、依頼の作画品質を全面達成したとは報告しない。

## 自己批評

- 改善：フードの布厚、胸郭と骨盤の分離、屈曲した膝、袖とパンツの圧縮皺、バッグの側面・肩ストラップが旧版より具体化した。沈み込み・蹴り出し・空中・着地の全身輪郭は別作画として存在する。
- 接地不足：支持足の画面座標が描き分け間でずれる。地面基準と靴の大きさも完全一致しない。固定画角なので揺れが隠れず、足滑り・縮尺揺れとして読まれる可能性が高い。
- 力の流れ不足：低い姿勢から空中ポーズへの切替が急で、支持足→骨盤→上体の順序は意図として指定したが、その意図どおりに実現した保証はない。骨盤移動量も弱い。
- 身体回転不足：肩と骨盤の回転差は一部読めるが、バッグが背中を覆う問題がなお残る。空中D06–07で両脚のパースが急変する。
- 追従不足：バッグと裾の角度差はあるが、独立した遅れと反動を連続して制御できていない。ストラップや留め具の形が変わる。余分な下がり紐があり、簡素化が必要。
- 中割り不足：露出表のkey/inbetweenは編集上の役割。生成モデルが前後キーを厳密に補間したという意味ではない。終盤D11–15は姿勢差が小さく、沈みと回復のリズムが弱い。
- 継続性：開始と終端のS03/S05接続は未検証。旧版は暗い背景・遠景人物、今回は明るい背景・大きな人物なので、比較は絵柄と動作の差を見る資料であり、同一構図の公平な撮影比較ではない。
- 黒フード・顔非表示・黒角形無地バッグ・主人公発光なしはシート上で確認。手は露出するが顔は露出しない。敵、D1、HUDは描いていない。

## 検証と再現

全15セルとF230拡大を静止視認。全動画を全尺デコードし、FFprobeで解像度・fps・フレーム数・尺を確認。結果はtechnical_validation.json。連続再生を視覚評価していないため、動きの自然さ・速度感は未判定。ソラの実視聴まで品質・演出HOLD。

`python3 source/build.py` で原画分割、全30f、露出表、通常/半速/比較MP4を再生成可能。必要：Python3、ffmpeg、ffprobe。AI生成そのものは非決定的。保存済み原画からの編集再現と、原画の同一再生成は区別する。source/prompts.jsonに実際のプロンプトを保存。
