# ZERO CODE STUDIO｜レビュー提出標準ルール

2026-10-13 監督指示。以後のレビュー提出に適用する。

1. 提出セットは **ZIP＋単独MP4＋主要PNG＋README＋検証結果**。ZIPには全成果物と検証資料を収録し、レビュー動画と主要比較画像を同じレビュー用フォルダのZIP外にも配置する。既存ZIPは上書きせず、新版が必要なら版番号を分ける。
2. 動画は原則24fps・H.264 MP4、互換性を考慮したyuv420p・faststartを用いる。尺、フレーム数、解像度、音声有無、容量、プロファイル／Levelを実測し、全フレームデコードを確認する。再生先で確認した範囲と未検証事項を分けて記録する。配布先の容量制限を確認し、超過時は承認済みの方法で提出する。
3. 主要PNGには版番号・フレーム番号を明示する。修正前後比較は同一カメラ・同一時点で示す。旧版がない新規案はその事実を記載する。
4. READMEに動画・PNG・ZIP・検証結果へのGitHubリンク、各内容、フレーム番号と番号体系、確認順序・ダウンロード方法、容量、未検証事項、判定状態を記載する。
5. 検証結果に検査日、使用方法、仕様・容量、SHA-256、ZIP整合性、単独ファイルとの一致、保護対象の変更有無を記録する。技術PASSと監督承認を混同しない。
6. 保存・コミット・プッシュは指定のレビュー専用ブランチのみ。main、既存素材、承認済みMASTER、指定保護フレームは変更しない。差分確認後に対象ファイルだけをコミットする。
7. DRAFT／監督レビュー待ちを明示し、公開前に明示的な承認を待つ。提出完了だけで公開・課金・本番反映・MASTER昇格を行わない。
