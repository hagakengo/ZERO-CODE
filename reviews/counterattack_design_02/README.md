## 修正差分

- P020〜025：拳を腹部（腰から上90px付近）へ下げ、上げたガードと分離。接触前のフレーム間移動量を約17.6→48.6→59.8→66.5→70.1pxへ加速。P023は拳先と腹部の間に69pxの空隙、P024は描画上1px重なる初接触、P025は腹部輪郭を24px圧縮、腰を8px沈める。
- P026〜035：腹部変形を先行。胸の移動を遅らせ、頭はP026まで位置を保ちP028で遅れを示す。腰の後退はP026以後。敵拳はP025〜027で短く留め、P028以後に引き戻す。反応と引き戻しの開始をずらす。
- P036〜055：P040までに後ろ足側へ重心代理値を移し、P041を接地最終時点、P042から前足を低く後方へ運ぶ。P044〜048の離地量を抑え、最大約15.76px（案01設計値72px）へ縮小。P050着地、P050〜051で腰・膝が受け、P054へ収束。両足位置はP050以降固定。
- 黒フード・顔非表示・無地の角形黒バッグを維持。案01の2D描画方式、固定カメラ、座標倍率、地面線を継承。P000〜015の身体姿勢を保持し、以後の修正区間は毎フレームで描画。

## 実施検証・制約

ffprobeで両MP4の24/1fps・72フレーム・3.000秒・H.264を実測。ffmpegで全フレームをエラーなしでデコード。接地中の足ずれ0px、膝反転0件、脚長誤差約2.6e-13px、重心代理値の支持区間外フラグ0件。これは簡易2Dリグの検査であり、物理的な荷重や衝撃の実証ではありません。

全72フレーム一覧、主要姿勢とP024比較を目視確認。黒フード、顔の遮蔽、バッグ形状、低い足軌道を確認。通常速度での端末再生・GitHub内蔵プレイヤーは未検証。打撃の強さ、腹部圧縮の読みやすさ、胸・頭・腰の因果、着地の自然さは監督の判定待ちです。完成映像・正式承認済み素材とは扱いません。

e00faddからの差分は `reviews/counterattack_design_02/` の追加のみ。案01、既存素材、main、r15.2 f226〜233、MASTERは変更しません。ローカルr15.2参照フォルダ20ファイルも処理前後のハッシュ一致を確認。公開・本番反映・MASTER昇格は実施しません。

## 再現

macOS、Python 3 + Pillow、PATH上のffmpeg / ffprobeを使用。Helvetica.ttcを使用するため、他OSではフォント指定を置き換えてください。

```sh
python3 source/build_design_02.py
python3 source/verify_review.py
python3 source/package_review.py
```

案01の隣に本フォルダを置いて実行。案01ZIP内のスクリプトから純粋関数・描画関数を抽出し、全72姿勢を同梱。r15.2の脚IK・靴・重心代理関数は読取りで取得し、source/baseline.pyへ同梱済み。動画生成に外部r15.2素材へのアクセスは不要です。外部保護ハッシュ検査はそのフォルダが存在するときのみ実施。
