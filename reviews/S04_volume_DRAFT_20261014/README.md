## 実際に作ったもの

Blender実行環境は確認できなかったが、代替としてPython/Pillowで三次元の関節座標とポリゴンメッシュを作り、固定透視カメラへ投影した。2Dの箱を動かしただけの疑似3Dではない。30枚のOBJ、全30fの関節座標、カメラ式、描画ソースを保存。プロ用にリグを組んだ完成キャラクターモデルでもない。

骨盤・肩に異なる回転曲線を与え、脚は各0.55mの二節IKで曲げる。支持足はワールド座標で固定し、接地中は靴の向きも固定。骨盤は沈み→上昇→着地圧縮→回復。バッグは固定寸法の直方体に、手設計の位置・回転の遅れを与え、左右ストラップは肩からバッグの同じ取付点へ結ぶ。慣性・ストラップ張力・摩擦を物理計算したものではない。

このガイドの15ポーズをbuilt-in image_genへ渡し、一枚の5×3原画シートへセル調で描き起こした。独立した文章指示だけでポーズを生成した前回から、全身の共通座標・関節構造・画角を参照する方式へ変更。ただし画像モデルによる正確な座標拘束はできなかった。

15セルを分割し、手で確認した靴底ランドマークをガイドへ位置合わせした。全セルに同じ拡大率2.447368421を使用し、個別のサイズ変更・身体ワープ・光学フローは使っていない。支持中は支持足、空中は両足中点へ平行移動して登録。各原画を2コマずつ露出し30fへ編集した。これは本格的な原画・中割りの完成ではなく、ガイド参照のAI原画＋接地登録実験。

## 数値と検査

- 通常版3D／2D：1080×1920、24/1fps、30f、1.250000秒。0.5倍版：24fps、60f、2.500000秒。H.264/yuv420p、無音。全動画の全尺デコード成功。
- ガイド支持足の基準点移動：左F216–226、F240–245／右F216–217、F233–245、各区間0.0m。脚長誤差は浮動小数点丸めの範囲。これはガイド内の拘束を検査した値であり、実写測定でも自然な運動の証明でもない。
- 肩腰の最大回転差：約31.59度。差があることは確認したが、魅力的な演技かは未判定。
- 2Dの接地ランドマークとガイドの差：接地対象の平均約19.45px、最大約101.05px。手動の概算ランドマーク、2コマ露出の各先頭フレームで評価。両足を同時に解く修正ではなく、もう一方の足がずれる。測定対象・各移動量はregistration_audit.csvに記録。
- 原画シートの実寸は1403×1121、1セル約280×374。指定した高解像度では返らなかった。1080×1920の原画を描き下ろしたわけではなく、細部は拡大されている。
- 接地監査のオレンジ丸はガイド座標、線は原画の手動ランドマークとの差。主人公の発光表現ではない。通常映像には監査マークなし。

## 自己批評・未達

**足接地**：3Dの支持基準点は安定した。2Dで支持足の大きな位置飛びを抑える登録を導入したが、靴形・足首角度・もう一方の足・終盤の脚の重なりは未解決。すべての足滑りを解消したとは言えない。2コマ打ちにより、ガイドの着地時刻と1f差が出る箇所もある。

**力の伝達**：支持区間・骨盤の上下と移動・肩腰の回転差は制御した。上体の並進は骨盤との固定オフセットが中心で、支持足→骨盤→上体の力学的な連鎖を十分に作れていない。質量、床反力、重心投影、接触トルクを解いていない。体重の説得力は未達の可能性が高い。

**バッグ**：ガイドでは寸法・取付点を固定できた。遅れは手設計の曲線で、重さを実証するシミュレーションではない。原画ではシルエットは概ね近いものの、厚み・底面・ストラップ・背中との距離が完全一致していない。

**フード・衣服**：ガイドのフードは硬い近似形。布の追従は計算していない。原画には折れ皺を描かせたが、皺・裾・フードの時間的追従を拘束できていない。布の遅れの検証は不足。迫力より構造確認を優先したため、アクションの速度・伸び・鋭さも弱い。

**修正試行**：最後の3ポーズの足の重なりをimage_genで修正した。両足は離れたが、ガイドより足幅が大幅に広がったため採用せず、rejected_correction/へ保存。改良に成功したと数えない。初回の位置合わせ試験はiteration01/に保存。

黒フード常時着用・顔非表示・黒角形無地バッグ・主人公発光なしは原画シートを静止確認。武器、敵、D1、HUDは追加していない。衣装・人物は今回のDRAFT候補であり、正式設定画の確定ではない。人間のアニメーターによる作画監督修正は未実施。通常速度の連続視聴を制作側で視覚評価していないため、演出PASSや旧版より自然という評価は出さない。S03/S05との接続も未検証。

## 再現と出典

Python3＋Pillow、ffmpeg、ffprobeで、本フォルダのsource/build_guide.py → source/assemble.py → source/verify.pyを実行。全3D座標・OBJ・ガイド、保存済み原画からの動画と検査を再生成できる。画像生成自体は非決定的で同一再生成は保証しない。プロンプトはsource/prompts.json。

guide_15_reference.pngは生成へ渡した初期カメラの固定入力。最終版は全体を同じ透視倍率で拡大し、初動右足と靴の接地拘束を修正した。共通骨格・ポーズの流れは同じだが、入力画像と最終ガイドがピクセル一致するわけではない。
